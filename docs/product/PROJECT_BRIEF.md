## 2. 프로젝트 개요

**메디스캔노트**는 예비 보건의료인이 의료영상에서 이상 부위를 직접 찾아보고, 자신의 판단을 기준과 비교하며, 피드백과 재도전을 통해 학습하는 웹 기반 의료영상 학습 지원 서비스다. 별도로 접한 비식별 의료영상의 관심 영역에 관한 AI 분석 정보도 학습 참고자료로 제공하는 방향을 포함한다.

캐치프레이즈는 **“찾아보고, 확인하고, 다시 도전하는 의료영상 판독 트레이닝”**이다.

상세 제품 범위는 [PRD의 제안 MVP 범위](./PRD.md#3-제안-mvp-범위), 실제 이용 순서는 [USER_FLOW의 전체 구조](./USER_FLOW.md#2-전체-구조)를 기준으로 한다.

## 3. 프로젝트 배경

기획자료가 제시하는 배경은 다음 세 가지다.

1. 학교와 실습기관마다 교육 기간, 내용, 평가와 지원 수준이 달라 학생이 접하는 의료영상 사례와 실습 기회에 차이가 생길 수 있다.
2. 정규 수업과 임상실습 이후 다양한 영상을 반복해서 보고 이상 부위를 직접 판단할 수 있는 자율학습 자료가 제한적이다.
3. 자신의 판단 위치를 기준과 비교하고, 오류를 피드백받고, 틀린 사례를 반복하는 지속적인 학습 환경이 부족하다.

### 배경 근거를 해석하는 원칙

내부기획서는 미국 의과대학생 472명 조사, 국내 42개 방사선학과 실습 운영 현황, 영국 학생 임상실습 조사, 아일랜드 방사선사 임상지도 연구를 근거로 든다. 대상 국가와 직군이 다르므로 이를 국내 방사선학과 학생 전체의 학습 부족이나 메디스캔노트의 효과를 직접 입증하는 자료로 확대 해석하지 않는다.

디지털·AI 기반 교육 연구도 해결 방식의 적용 가능성을 보여주는 보조 근거로 사용한다. 해당 연구가 메디스캔노트의 ROI 평가, 오답 재학습 또는 사용자 영상 AI 분석의 학습 효과를 직접 검증한 것은 아니다.

## 4. 문제 정의

### 핵심 문제

의료영상 판독 교육에서 학생이 실제 영상을 보고 이상 부위를 직접 판단한 뒤 그 결과를 객관적으로 평가·복습하거나, 별도로 접한 의료영상의 관심 영역에 대한 의심 소견과 관련 정보를 확인할 수 있는 통합 훈련 환경이 부족해 판독 역량을 체계적으로 향상시키기 어렵다.

### 사용자가 겪는 문제

- 자신이 표시한 위치가 기준 영역과 얼마나 일치하는지 즉시 확인하기 어렵다.
- 다양한 사례를 반복해서 풀거나 부분정답·오답 사례만 모아 재도전하기 어렵다.
- 별도로 접한 영상의 관심 영역에 관한 소견과 관련 정보를 여러 자료에서 직접 찾아 비교해야 한다.
- 학교와 실습기관에 따라 접할 수 있는 사례와 피드백 기회에 차이가 있다.

### 문제를 해결하지 못할 때의 손실

- 이론을 실제 영상에 적용하는 판단 경험을 체계적으로 축적하기 어렵다.
- 잘못 판단한 위치를 발견하고 교정하거나 개인의 취약 영역을 반복 보완하기 어렵다.
- 교육 환경에 따른 사례 경험과 반복 훈련 기회의 차이가 지속될 수 있다.

## 5. 프로젝트 목표와 비목표

### 목표

- 정답을 보기 전에 의료영상의 관심 영역을 직접 찾는 능동적 학습 경험을 제공한다.
- 사용자의 판단과 준비된 기준을 비교해 오류를 이해할 수 있게 한다.
- 결과 확인을 해설, 오답 기록, 동일 사례 재도전으로 연결한다.
- AI 분석 정보를 확정적 진단이 아닌 안전한 학습 참고자료로 제공한다.
- 뇌, 흉부, 복부, 무릎을 대상으로 핵심 학습 흐름의 사용 가능성을 검증한다.

기능별 요구사항과 우선순위는 [PRD의 기능 요구사항](./PRD.md#4-기능-요구사항), 기준 ROI 평가는 [ROI_EVALUATION](../ai/ROI_EVALUATION.md), AI의 역할은 [DATA_AI](../ai/DATA_AI.md)를 따른다.

### 비목표

- 확정적 의료 진단, 치료 권고 또는 진료 의사결정
- 학교 교육, 임상실습 또는 의료전문가의 판단 대체
- 실제 환자 개인정보나 비식별화되지 않은 의료데이터의 사용
- 전문 판독보고서 작성 플랫폼 또는 임상 PACS의 재현

## 6. 타깃 사용자

### 초기 핵심 사용자

의료영상 교육과 임상실습을 경험하며, 영상에서 이상 부위를 직접 판단하고 반복적으로 학습하려는 방사선학과 중심의 예비 보건의료인이다. 내부기획서의 대표 페르소나는 24세 방사선학과 4학년 학생이다.

주요 사용 특성은 다음과 같다.

- 자기주도 학습과 시각 자료를 선호한다.
- 실전형 문제와 반복 학습을 중요하게 생각한다.
- 자신의 ROI와 기준 영역의 차이를 객관적으로 확인하고 싶어 한다.
- 수업 또는 인터넷에서 접한 영상의 관심 영역에 관한 정보를 확인하고 싶어 한다.
- PC와 웹 환경에서 수업·실습 후 복습 또는 시험 준비에 사용한다.

### 확장 사용자

- 의료영상의 기초 구조와 소견 이해가 필요한 다른 보건의료계열 학생
- 전문 증례와 콘텐츠가 확보된 이후의 전문 수련 의료인
- 교수자·증례 관리 기능이 추가된 이후의 대학, 보건의료교육기관, 수련병원

확장 사용자의 기능 포함 여부는 이 문서가 아니라 [PRD의 MVP 제외 범위](./PRD.md#7-mvp-제외-범위)에서 관리한다.

## 7. 핵심 가치와 검증 질문

| 핵심 가치 | 검증 질문 |
| --- | --- |
| 능동성 | 사용자가 별도 설명 없이 케이스 선택, ROI 표시, 제출을 완료할 수 있는가? |
| 객관적 비교 | 사용자 ROI와 기준 ROI의 비교가 판단 오류를 이해하는 데 도움이 되는가? |
| 이해 연결 | 결과와 해설·의학용어·참고자료의 연결을 이해할 수 있는가? |
| 반복성 | 부분정답·오답 확인이 오답노트와 동일 케이스 재도전으로 자연스럽게 이어지는가? |
| 안전한 학습 보조 | 사용자가 AI 결과를 진단이 아닌 오류 가능성이 있는 학습 참고 정보로 이해하는가? |

검증 대상 표본, 과업 성공률, 만족도, 재도전율 등의 목표값은 아직 확정하지 않았다. 제품 완료 조건은 [PRD의 시나리오 단위 완료 조건](./PRD.md#8-시나리오-단위-완료-조건), 구체적인 검증은 [TEST_PLAN](../testing/TEST_PLAN.md)에서 관리한다.

## 8. 프로젝트 수준의 제약

- 의료 진단이 아닌 교육 목적을 모든 기능과 표현의 기준으로 삼는다.
- 개인정보가 없거나 적절히 비식별화되고 이용 조건을 확인한 의료영상만 사용한다.
- 공개 데이터셋의 기준 ROI와 라벨을 임상적으로 검증된 절대 정답으로 표현하지 않는다.
- ROI 평가 규칙, AI 모델, 기술 스택처럼 미확정된 사항은 확정된 목표처럼 서술하지 않는다.

세부 데이터·AI 제한은 [DATA_AI의 한계와 금지 사항](../ai/DATA_AI.md#10-한계와-금지-사항), 개인정보·안전 경계는 [ARCHITECTURE](../system/ARCHITECTURE.md#6-개인정보안전-경계)를 따른다.

## 9. 원본과 변경 관리

- 제품 기획의 기준은 최신 내부기획서인 노션 Markdown이다.
- 산출물 기획서는 프로젝트 완료 후 제출할 공식 문서이며 내부기획과 정합성을 유지한다.

# 메디스캔노트 테스트 계획

> **문서 역할:** 기능·데이터·개인정보·AI·종단 흐름의 검증 항목을 한곳에서 관리한다.  
> **이 문서가 기준인 내용:** 테스트 범주, 필수 검사, 발표 수용 시나리오  
> **이 문서에 기록하지 않는 내용:** 구현 일정, 제품 요구사항 원문, 테스트 코드  
> **상태:** 기준안 / 세부 도구와 합격 수치 미확정  
> **기준일:** 2026-09-11

## 2. 단위 테스트

- ROI 좌표 정규화와 선택된 겹침 지표
- 정답·부분정답·오답 경계값과 평가 규칙 버전
- 약 40% 시작값의 바로 아래·같음·위 경계
- 빈 ROI, 화면 밖 ROI, 지나치게 큰 ROI, 다중 ROI·병변
- 이미지 리사이즈·확대·축소 후 좌표 일치
- 지원 부위·영상 종류 라우팅과 지원 밖 입력 거절
- 학습 경험별 초기 추천과 판정·재도전 이력별 갱신
- 사용자 직접 선택 난이도가 추천으로 덮어써지지 않는지 확인
- 사용자 노출 결과에 진단·치료 표현이 섞이지 않는지 확인

## 3. 프론트엔드와 계약 테스트

- 회원가입 필드, 이전·다음, 동의, 입력 오류와 데모 상태
- 비밀번호 7자·8자·64자·65자 경계와 영문·숫자·특수문자 포함 여부 검사
- 이메일 앞뒤 공백 정리, 중간 공백·잘못된 기본 형식 거절, 254자·255자 경계 검사
- `전체 동의`가 이용약관·개인정보·만 14세 확인·선택 마케팅 동의를 모두 함께 선택하거나 해제함
- 필수 약관·연령 확인 후 마케팅 미동의 상태에서도 다음 단계 진행 가능
- `다음` 클릭 시 이메일 중복 시연 검사를 수행하고, 중복이면 이동 없이 안내 문구 표시
- 이메일 수정 시 중복 오류 상태 초기화
- 한글 포함 닉네임 2~8자와 영어·숫자 닉네임 4~14자 경계값 검사
- 한글·영어·숫자 혼용 허용, 숫자 전용·공백·특수문자 닉네임 거절
- 닉네임 확인 후 수정 시 중복 확인 상태 초기화
- 닉네임 데모는 `사용중닉네임`과 `조회실패`만 사용하고 `가입실패` 특수값 없이 일반 닉네임으로 가입 완료
- 선택 마케팅 동의 없이 가입 진행 가능
- 가입 경로를 비운 상태로 가입 가능하며 `기타` 선택 시에만 직접 입력 요구
- 학교·교육과정·학년 필드가 화면과 요청에 없음
- 데스크톱과 기본 모바일 너비에서 입력·버튼·약관이 겹치거나 잘리지 않음
- ROI 생성·이동·크기 변경·삭제와 키보드·포인터 조작
- 문제 응답에 기준 ROI·병명·정답 해설이 포함되지 않음
- 판정별 결과, 빈 목록, 로딩, 네트워크 실패와 재시도
- API 스키마와 프론트 타입의 호환성

## 4. 백엔드 통합 테스트

- 제출 → 평가 → 시도 저장 → 부분정답·오답 오답노트 생성의 일관성
- 재도전 연결과 사용자 간 시도·오답 접근 차단
- 중복 제출 처리와 과거 평가 규칙 버전 재현
- 이메일·닉네임 중복, 계정 등록, 약관 버전과 연령 확인
- 인증메일 만료·재사용·재발송과 비밀번호 저장 안전성
- 미인증 로그인 후 학습·ROI·오답·AI API 차단
- 인증 완료 후 동일 권한 검사가 통과하는지 확인
- 전공 목록·기타·비전공 입력 검증
- 학습 경험 저장, 추천 갱신과 사용자 직접 변경

## 5. 데이터 품질 테스트

- 파일 해시, 손상 파일, 누락 라벨과 좌표 범위
- 영상과 ROI 크기 일치
- 환자·검사 단위 중복과 데이터 누수
- 출처·버전·라이선스·허용 목적·비식별화 정보 필수 확인
- 원 라벨 생성 정보가 없는 케이스 차단
- DICOM 사용 시 헤더와 픽셀 번인 개인정보 검사
- 학습·검증·테스트와 제품 문제 케이스의 분리

## 6. 개인정보와 삭제 테스트

- 수집하지 않기로 한 학교·교육과정·학년이 화면·API·DB에 없음
- 이메일·닉네임·전공·동의·접속·학습 이력이 로그와 오류에 불필요하게 노출되지 않음
- 금지된 메타데이터와 픽셀 번인 의심 입력 차단 또는 안전 실패
- 성공·모델 오류·네트워크 오류·시간초과·취소·재시작 후 임시 파일 삭제
- 로그·오류 추적·캐시·썸네일·백업에 원본이나 식별자가 남지 않음
- 사용자 입력이 모델 재학습 데이터로 이동하지 않음

## 7. AI 평가

- 분류: 필요 시 AUROC, 민감도, 특이도, 보정 지표
- 탐지: 필요 시 mAP, 병변 단위 민감도, 거짓 양성
- 분할: 필요 시 Dice, IoU와 경계 오차
- 부위·질환·데이터 출처·병변 크기별 성능과 실패 사례 분리
- 지원 밖 입력, 낮은 신뢰도, 빈 결과의 제한 응답
- 데이터셋 라벨 대비 기술 평가와 임상 성능 검증을 구분

최종 지표와 합격 기준은 모델 과제가 정해진 뒤 [DATA_AI](../ai/DATA_AI.md)와 [DECISIONS](../project/DECISIONS.md)에서 승인한다.

## 8. 종단·발표 수용 테스트

### ROI 학습

`회원가입/로그인 → 학습 경험 → 난이도 확인·변경 → 부위 선택 → ROI 제출 → 피드백 → 부분정답·오답 자동 저장 → 추천 갱신 → 재도전 → 이전 결과 비교`

### 사용자 영상 분석

`비식별 입력 고지 → 파일·정지 캡처 선택 → 관심 ROI → 부위별 AI → 결과와 한계 → 입력 삭제`

### 발표 준비

- 중간발표와 최종발표용 고정 시나리오
- 데모 계정과 사용 허가가 확인된 공개 샘플
- 네트워크·모델 실패 대비 절차
- 승인된 브라우저, 반응형, 접근성과 오류 복구

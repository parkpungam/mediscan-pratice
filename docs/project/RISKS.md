# 프로젝트 위험 기록

> **문서 역할:** 의료영상·개인정보·AI·일정 위험과 통제 방법을 추적한다.  
> **이 문서가 기준인 내용:** 위험 수준, 영향, 현재 통제, 남은 결정  
> **이 문서에 기록하지 않는 내용:** 상세 요구사항, 테스트 절차, 개별 결정의 승인 이력  
> **상태:** 위험 기준안 / 남은 결정 존재  
> **기준일:** 2026-09-11

## 1. 사용 방법

- 위험이 실제 요구사항으로 확정되면 담당 기준 문서와 [DECISIONS](./DECISIONS.md)를 함께 갱신한다.
- 검증 방법은 [TEST_PLAN](../testing/TEST_PLAN.md)에 기록한다.
- 데이터·AI 기술 세부는 [DATA_AI](../ai/DATA_AI.md)와 [ROI_EVALUATION](../ai/ROI_EVALUATION.md)을 따른다.

## 2. 위험 목록

| 위험 | 수준 | 현재 통제 | 남은 결정 |
| --- | --- | --- | --- |
| 사용자 영상에 환자 이름·병원번호·촬영정보 포함 | 치명 | 비식별 자료만 허용, 사전 고지, 메타데이터·픽셀 검사, 안전 실패 | 자동 검사 범위와 차단 기준 |
| 즉시 삭제가 오류·백업·로그에서 지켜지지 않음 | 치명 | 격리 임시 스토리지, 짧은 만료, 공통 정리 작업, 삭제 테스트 | 삭제 정책 최종 승인과 로그 범위 |
| 공개 데이터 라벨을 임상 정답으로 오해 | 높음 | `데이터셋 제공 기준 ROI`, 출처·검수 수준 표시 | 위험 수용과 고지 문구 |
| AI 결과를 진단·실제 질환 확률로 오해 | 높음 | 교육용 참고 정보, 진단·치료 표현 금지, 지원 범위 표시 | `가능성`의 의미와 출력 계약 |
| 잘못된 신체 부위 모델 호출 | 높음 | 명시적 부위 선택과 지원 영상 종류 확인 | 부위별 모델·어댑터 구성 |
| 큰 박스·다중 병변으로 ROI 채점 왜곡 | 높음 | 면적 과대 페널티와 다중 매칭 후보 | 지표·임계값·매칭 규칙 |
| 데이터 라이선스가 데모·재배포를 허용하지 않음 | 높음 | 공식 출처와 버전별 허용 범위 기록 | 채택 데이터셋과 확인 담당자 |
| 학습·검증 누수로 AI 성능 과대평가 | 높음 | 환자·검사 단위 분리와 중복 검사 | 분할 정책과 합격 기준 |
| 네 부위 동시 범위로 일정 지연 | 높음 | 부위별 최소 검증 조합과 단계 완성 | 최소 케이스와 우선순위 |
| 화면 공유가 전체 화면을 지속 전송 | 높음 | 사용자가 확정한 정지 캡처·ROI만 전송하는 안 | 캡처 단위와 전송 경로 |
| 전공·자기평가만으로 실력을 단정 | 중간 | 실제 판정·재도전으로 보정, 추천 이유와 직접 변경 | 최소 문제 수·가중치·전환 기준 |
